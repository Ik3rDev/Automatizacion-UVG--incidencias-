# Automatización de Registro y Notificación de Incidencias

## Descripción

Este proyecto consiste en la automatización del proceso de registro y notificación de incidencias utilizando herramientas de Microsoft como Forms, SharePoint y Power Automate.

## Problema

No existía un protocolo estandarizado para documentar incidencias ni un sistema eficiente para notificarlas, lo que generaba retrasos y desorganización.

## Solución

Se diseñó un flujo automatizado que:

* Permite registrar incidencias mediante Microsoft Forms
* Almacena la información en SharePoint
* Envía notificaciones automáticas en tiempo real usando Power Automate
  
## Resultados

* Reducción del tiempo de gestión de incidencias
* Mejora en la trazabilidad de la información
* Eliminación de procesos manuales
